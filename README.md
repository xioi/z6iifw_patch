# Z6II Firmware Patch

适用于 **Nikon Z 6II、C 固件 1.70** 的原生 SD 模块加载器与扩展模块。项目与尼康官方无关，仅支持这一机型和版本，不要用于其他相机或固件。

## 项目目的

通过一次固件升级安装 SD 模块加载器，之后只需替换存储卡根目录的 `Z62APP.BIN`，即可更新扩展功能，不必重复刷写完整固件。加载器支持模块校验、重定位和缓存同步，依次尝试 `B:\Z62APP.BIN` 与 `A:\Z62APP.BIN`。

修改固件和运行原生模块存在死机、数据丢失或无法启动的风险。安装前请备份照片和存储卡，并确保相机电量充足。

## 稳定功能

### 竖屏 UI

- 根据机身方向旋转后屏拍摄信息和已适配的菜单。
- 同步拍摄界面的触控区域，支持 4×3 i 菜单与部分二级设置页。
- 场景图像本身保持原方向；实体 MENU、回放及尚未适配的覆盖层保持原厂布局。

### 解除录像时长限制

- 普通录像的时长状态同步使用存储卡容量计算值，不再受原厂 29 分 59 秒配置限制。
- 界面最多显示 `999分59秒`，录像任务仍保留真实容量值。
- 存储空间、文件数量、电池和过热保护仍然有效；100/120p 等特殊录像路径不在此功能范围内。

### 固化视频方向

- 普通内录 MOV/MP4 在开档时锁定机身姿态，将方向写入视频轨显示矩阵。
- 录制中转动相机不会改变当前文件的方向；原厂分段打开新文件时重新读取姿态。
- 不重编码或旋转实际像素，播放器需要支持视频轨方向元数据。

## 安装教程

### 准备

1. 一台运行 **C 1.70** 的 Nikon Z 6II。
2. 尼康原厂 `Z6_2_0170.bin` 升级包；项目不附带原厂固件。
3. 一张已备份的存储卡，以及电脑上的 Python 3。生成器只使用 Python 标准库，**不需要 K8、`key.json`、NumPy 或编译工具**。

### 第一步：生成 SD 模块加载器固件

在项目根目录执行：

```sh
python3 tools/build_loader_firmware.py /path/to/Z6_2_0170.bin \
  --output release/Z6_2_0170_loader.bin
```

将 `/path/to/Z6_2_0170.bin` 替换为原厂文件的实际路径。脚本会检查原厂包哈希，应用内置的二进制加载器补丁，并验证模块 CRC、包 CRC、签名及解密回读结果。只有全部检查通过才写入输出文件。

当前版本正确输出的 SHA-256 为：

```text
aa5e2e8599f9126e92476c64e7de7c966d662d101e7d9ab19a358d1bb19ceacf
```

macOS 可运行 `shasum -a 256 release/Z6_2_0170_loader.bin` 核对，Linux 使用 `sha256sum`。若输出已存在，确认可以替换后添加 `--force`；脚本不会覆盖输入的原厂固件。

### 第二步：安装加载器

1. 将生成的 `Z6_2_0170_loader.bin` 复制到存储卡根目录。
2. 断开 USB 连接，在相机中选择「设定菜单 → 固件版本 → 升级固件」，确认升级。
3. 升级完成后删除卡上的加载器升级包。

已经安装过相同加载器时，不必重复此步骤。

### 第三步：安装全功能模块

1. 删除存储卡根目录已有的 `Z62APP.BIN`，不要直接依赖覆盖写入。
2. 将项目提供的 `release/Z62APP.BIN` 复制到存储卡根目录，文件名保持不变。
3. 等待存储卡访问结束，关机后重新开机。
4. 分别检查横屏、左右竖屏、菜单、拍摄参数调整、普通录像及视频回放。

`release/Z62APP.BIN.json` 是电脑端核对功能配置与 SHA-256 的清单，不需要复制到相机。当前模块的 SHA-256 为：

```text
a6874523f365133a98ac6c892f9b1f0d9d210e446bbf1490b2af6ba842580d3a
```

### 停用或恢复

- **停用扩展功能**：删除存储卡根目录的 `Z62APP.BIN`，完整关机后重新启动。
- **移除加载器**：刷回尼康原厂 Z6II C 1.70 升级包。
- **模块异常**：关机并取出存储卡后重新启动；不要在相机仍访问存储卡时拔卡。
